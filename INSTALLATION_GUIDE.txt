TELEGRAM COMMUNITY MIGRATOR PRO — INSTALLATION GUIDE

GETTING THE WINDOWS INSTALLER
1. Upload the complete project folder to a GitHub repository.
2. Open the repository's Actions tab.
3. Select "Build Windows installer".
4. Select "Run workflow".
5. Wait for the green successful build result.
6. Open the completed run and download "TelegramCommunityMigratorPro-Windows-Installer".
7. Extract the downloaded ZIP file. Find TelegramCommunityMigratorPro_Setup.exe.

INSTALLING
1. Double-click TelegramCommunityMigratorPro_Setup.exe.
2. Follow the installer prompts and click Install.
3. When installation finishes, click Finish.
4. Launch Telegram Community Migrator Pro from the desktop shortcut or Windows Start Menu.

FIRST USE
1. Create a Telegram bot using @BotFather.
2. Open Connect Telegram in the app and paste the bot token.
3. Add the bot to the destination Telegram group as an administrator with invite-user permission.
4. Save the destination group and any source group references.
5. Import a CSV containing contacts who have explicitly agreed to receive an invitation. Set consent to TRUE.
6. Open Migration Manager, select a consented member and destination group, and generate a join-request link.

CSV HEADERS
name,username,telegram_id,source,destination,consent

IMPORTANT
This application does not scrape arbitrary Telegram groups or bypass Telegram privacy controls. It does not silently add members. Telegram Bot API cannot enumerate all members of arbitrary groups. Each invite is a join-request link; the person chooses whether to join.

The Windows installer is generated by GitHub Actions. This project package itself is source code and build configuration, not a prebuilt Windows installer.
